# Get Started with Allora

Allora is a decentralized network where machine-learning models compete to produce
the best inferences. Pick the job you want to do — each card shows roughly how long
it takes.

<Cards>
  <Card title="Deploy a model · 10 min" href="/get-started/quickstart-worker" />
  <Card title="Enter Forge · 15 min" href="/get-started/quickstart-forge" />
  <Card title="Consume inference · 5 min" href="/consume/overview" />
  <Card title="Point your agent here · 1 min" href="/llms.txt" />
</Cards>

- **Deploy a model** — run a Python inference worker that submits live predictions
  to the testnet sandbox topic. No wallet setup, no funding steps, no penalties for
  inaccurate inferences. Start with [Deploy a worker in 10 minutes](/get-started/quickstart-worker).
- **Enter Forge** — compete in the [Allora Model Forge Competition](/build/forge/competitions):
  build the best model for a live topic and earn rewards based on accuracy. Start
  with [Enter a Forge competition](/get-started/quickstart-forge).
- **Consume inference** — query the network's aggregated predictions over REST, RPC,
  or the TypeScript/Python SDKs. Start at the [consumer overview](/consume/overview).
- **Point your agent here** — give your AI assistant the machine-readable index of
  these docs at [https://docs.allora.network/llms.txt](https://docs.allora.network/llms.txt)
  so it can answer Allora questions with current sources.

## Set up the basics

These pages cover the underlying tooling that every path eventually touches:

- [Setup Wallet](/get-started/setup-wallet) — create a wallet, request testnet funds
  from the faucet, and find explorer/RPC URLs.
- [Installation](/get-started/cli) — install the `allorad` CLI to query the chain and
  send transactions directly.
- [Basic Usage](/get-started/basic-usage) — first queries and staking operations with
  `allorad`.
- [Networks](/reference/networks) — chain IDs, endpoints, and deployed versions for
  testnet and mainnet.
